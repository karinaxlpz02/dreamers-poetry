# Dreamers Poetry

An interactive, generative poetry website about queer virtual desire. Click anywhere to begin a new passage and rearrange the drifting clouds of hearts and stars. The underlined heart links to the writing that inspired each passage.

Original texts are assembled in the browser; they are not quotations from the referenced works. Uses seven randomly shuffled pixel and cursive Google Fonts. Poems automatically continue in overlapping layers; a click fades the previous layers and starts fresh.

Open `index.html` or serve this directory with `python3 -m http.server 4173`.
