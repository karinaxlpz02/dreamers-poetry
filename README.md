# Dreamers Poetry

An interactive, generative poetry website about queer virtual desire. Click anywhere to begin a new passage and rearrange the drifting clouds of hearts and stars. The underlined heart links to the writing that inspired each passage.

Original texts are assembled in the browser; they are not quotations from the referenced works. Uses seven randomly shuffled pixel and cursive Google Fonts. Poems type simultaneously into differently sized regions of a randomized grid on a pale yellow circular gradient. Clicking regenerates the layout and restarts every poem.

Open `index.html` or serve this directory with `python3 -m http.server 4173`.
